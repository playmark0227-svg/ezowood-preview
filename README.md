# Ezowood Hokkaido

Website design preview for a wooden-pen brand using Hokkaido wood.

## Pages

- Home: forest and handwork film, first pen, material, craft, everyday use, gifting, care, journal, questions and ordering plan.
- Our story, Hokkaido wood, making, gifting, and use & care: four chapters each.
- Journal: six complete illustrated articles.
- Product: gallery, specifications, natural variations, usage scenes and ordering plan.
- Shopping guide: planned conditions and 20 questions with category filters.
- Contact, browser-local cart, sample checkout and preview completion.

Japanese, English, and Simplified Chinese are available throughout.

## Local preview

Serve this directory with a static HTTP server. There is no build step.

## Preview scope

Images and film are illustrative; actual product, workshop and packaging photographs remain to be supplied. Price, final specifications, payment methods, delivery coverage, and aftercare conditions remain to be confirmed. No actual orders, payments, reservations, registrations or emails are submitted. Customer information is shown as samples. Only language preference and preview cart quantity are stored in the browser.

## Publication

GitHub Pages serves the main branch at its root. The site uses hash routes. Keep source answer documents, private production records, credentials and QA files outside this directory.
