# Ezowood Hokkaido preview

A static design preview of a Hokkaido wooden-pen brand.

## Preview routes

- `#/` — brand homepage with a silent image film
- `#/story` — the brand, wood, craft, and gifting
- `#/product` — the first pen, gallery, and preview cart
- `#/guide` — planned sales and delivery information
- `#/cart` — browser-local cart
- `#/checkout` — checkout walkthrough with sample information
- `#/contact` — contact information pending launch

Use `?lang=en` or `?lang=zh` before the hash to open the translated version. The language and cart quantity are the only data saved in the browser.

## Boundaries

This is a public design preview, not a live store. Product photographs, the forest film, and workshop photographs are illustrative concepts. The film is a silent motion treatment of the forest image. Product shape, exact specifications, price, payment methods, terms, and shipping coverage are not finalized. The 20-pen initial reservation plan and 1–2 week production/shipping target come from the project brief. No order, payment, notification subscription, email, or personal information is sent to a server.

The preview uses a single entry point and hash routing so every page works on GitHub Pages. No third-party shop assets or copy are included. The original ezowood brand artwork is used in monochrome.

## Local preview

Serve this folder with any static HTTP server and open `index.html`.
